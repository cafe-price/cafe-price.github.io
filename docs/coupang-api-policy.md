# 쿠팡 파트너스 검색 API 기준

확인일: 2026-11-26. 공식 사이트의 현재 화면을 직접 확인했다.

- 출처: https://partners.coupang.com/#help/open-api
- `문서` 탭 → v1 → GET `/products/search`: **1분당 최대 50번 호출**.
- `limit`: 최대 상품 수 10개, 기본값 10개. `keyword` 필수.
- `자주묻는 질문` → API 호출 제한: API별 한도는 문서 탭 참조. 비정상적인 과도한 호출은 제한 대상이며 한도 도달 시 24시간 제한.
- `가이드`: HMAC 인증, Access/Secret Key 비공개 보관.
- 2024-12-16 공식 PDF에는 Search 시간당 10회로 기재되어 있다. 현재 온라인 문서와 다른 과거 기준이다. 2025-07-14 가이드는 API 전용 온라인 문서로 연결한다.
- V2 Reco API의 분당 100회와 캐시/노출 측정 규칙은 개인화 추천 API 설명이며 Search의 호출 한도로 사용하지 않는다.

## 이 사이트의 보수적 운영 설정

- 기존 상품만 조회. 공식 Search API, `limit=10`, 등록된 기존 키 사용.
- 최소 8초 간격, 최근 61초에 최대 8회, 최근 24시간에 실패 포함 최대 900회. 요청 전 호출 사용량을 예약·저장한다.
- 한국시간 매일 07:00/12:00/17:00/22:00에 GitHub Actions 실행, 1회 최대 600회/90분. 오늘 실제 확인된 상품은 중복 목표에서 제외한다. 키/PC/프록시를 바꿔 제한을 우회하지 않는다.
- HTTP 401/403/429 또는 오류 응답을 받으면 즉시 중단하고 `apiPaused=true`를 보존한다. 원인 검토 전 다음 예약도 API를 호출하지 않는다. 기타 오류도 최소 24시간 중지한다.
- 매 25회 중간 저장, 종료 시 최종 저장. 상품 가격과 시간은 동일 productId 및 vendorItemId의 유효한 가격 응답만 반영한다. 2026-11-26 사용자 승인으로 일반배송도 가격을 갱신하고 실제 배송 조건을 함께 표시한다.
- 같은 가격도 정상 확인이며, 검색 결과에 옵션이 없으면 가격/확인 시각을 만들지 않는다. API 정상 응답 여부와 목표 상품 미발견은 별도로 기록한다.
- 예약 실행 지연/누락 가능: https://docs.github.com/en/actions/how-tos/troubleshoot-workflows

공식 한도 준수와 전체 상품 검색 성공은 별개다. 정확한 옵션이 검색 결과에 없거나 GitHub 예약이 지연되면 525개 전부의 일일 가격 확인은 보장할 수 없다. 경고가 절대로 없다는 보장도 하지 않는다.
